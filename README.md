# 🌤 Smart Weather Assistant

A modern weather web app that fetches **real-time weather** data and provides **human-friendly advice** (umbrella reminders, heat alerts, wind warnings, etc.) — not just numbers.  

It adapts backgrounds & animations (sun, rain, snow, clouds) for a **realistic, attractive experience**.

---

## 🚀 Features
- Search by **city, district, or pincode**  
- 📍 **GPS auto-detect** for instant local weather  
- 🌞 Dynamic **backgrounds & animations** (sun, rain, clouds, snow)  
- 🗣️ **Actionable suggestions** (e.g., carry umbrella, drink water, wear jacket)  
- 🕒 Local time + location displayed  
- ⚠️ Friendly error handling  
- ♿ Accessibility: clear icons, high-contrast design, readable text
